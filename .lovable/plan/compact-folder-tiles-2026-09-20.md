# Compact folder tiles

## What will change
- Keep documents in their existing preview cards.
- Replace folder cover cards with compact, rounded rectangular tiles at the same grid width.
- Show a larger folder icon beside the folder name; the selected folder color affects only this icon.
- Preserve existing folder actions, double-click renaming, starring, dragging, and opening behavior.
- Remove the ombre folder-cover rendering and its now-unused color-gradient helpers.

## Technical details
- This is a presentation-only change in the home browser.
- Google Drive will not be connected, synced, or used for storage.
- Folder and document data remain in Lovable Cloud exactly as they are now.
